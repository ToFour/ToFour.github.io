Embodied Multimodal World Modeling with 4D Scene Graphs for Long-Distance Teleoperation

Problem

Long-distance robot operation suffers from network delay and temporary disconnections, causing a mismatch between human-issued instructions and the robot's actual environment. Simply pausing execution or relying on static perception is impractical.

Figure 1: Problem formulation. The remote robot captures a camera frame at time T1, sent to the local operator with downlink latency Δt1. The operator issues a command u based on I(T1), transmitted back with uplink latency Δt2. During [T1, Tn], the environment may evolve under three scenarios: static (A), simple change (B), and complex change (C).

System Overview

The pipeline begins with an input RGB-D sequence, which undergoes keyframe extraction to eliminate temporal redundancy. In the perception stage, open-vocabulary models (GroundingDINO) perform object detection and segmentation to define semantic nodes. These nodes are organized into single-frame scene graphs using a polar-coordinate-based spatial representation. Simultaneously, a multi-modal MOT module (DeepSORT) establishes stable temporal edges across frames. Finally, the 4D scene graph is structuralized into a compact JSON format, serving as a symbolic world model for the LLM to generate executable robot action sequences.

Figure 2: Overview of the 4D-OVSG system. The process begins with an input RGB-D sequence, undergoing keyframe extraction, open-vocabulary detection and segmentation, semantic map construction, multi-object tracking, scene graph construction with polar coordinate representation, and finally JSON structuralization for low-level action planning.

Real-Robot Experiments

Validated on the JAKA S5 platform across six-level network latency conditions (0–300s), the system maintains robust task execution even under minute-level delays. The GMM-based keyframe extraction module reduces computational redundancy while preserving critical scene transitions.

Figure 3: Real-robot experiments on JAKA S5 across three scenarios: static environment (A), simple change (B), and complex change (C). The system receives delayed camera frames I(T1) and executes commands based on the 4D scene graph world model.
